\# Toxicity Classification Model Analysis



Этот репозиторий содержит демонстрационный скрипт анализа и оценки ML-модели для классификации токсичности химических веществ.



\*\*Примечание:\*\* Это часть более крупного проекта. Исходные данные и пайплайн подготовки признаков скрыты в целях сохранения коммерческой тайны. Данный скрипт демонстрирует навыки работы с ML-библиотеками, оценки качества моделей и продуктового мышления.



\## Что делает скрипт



1\. \*\*Загружает мастер-таблицу\*\* с рассчитанными молекулярными дескрипторами и классами токсичности.

2\. \*\*Обучает модель RandomForestClassifier\*\* с балансировкой классов.

3\. \*\*Оценивает качество\*\* не только стандартными метриками (accuracy, balanced\_accuracy, f1\_macro), но и кастомной бизнес-метрикой, учитывающей стоимость ошибки в соседние классы (доля предсказаний, ошибающихся не более чем на 1 класс опасности).

4\. \*\*Реализует скрининговый режим\*\*: объединяет высокоопасные классы (1+2) для максимизации чувствительности (sensitivity) — это критично для бизнес-задачи выявления опасных веществ.

5\. \*\*Анализирует важность признаков\*\* (Feature Importance) для интерпретации модели.



\## Стек технологий

\- \*\*Язык:\*\* Python 3.9+

\- \*\*Анализ данных:\*\* Pandas, NumPy

\- \*\*Machine Learning:\*\* Scikit-learn (Pipelines, Imputers, Stratified Split, RandomForest)

\- \*\*Метрики:\*\* accuracy, balanced\_accuracy, f1\_macro, confusion\_matrix, sensitivity
